Kade Ops Agent
Built by Eugenio Díaz

Ask Kade's operations agent.

It looks things up in Kade's policies, supplier contracts and ERP before answering, and tells you where each fact came from. It can also write short reports and open helpdesk tickets. Kade Logistics is a made-up freight forwarder, and every document and invoice here was invented for the demo.

Enter to send · Shift+Enter for a new line

Every configuration gets the same questions, and a script grades each answer. It checks that the right facts are there, that no numbers were made up, that the agent used the right tool and that it didn't open a ticket nobody asked for. The model behind this demo was chosen from these results.

Retrieval

Each of the 8 documents is split into sections and indexed with BM25: about 50 lines of Python and no vector database, which is plenty for this many documents. A bigger corpus would get embeddings and hybrid search.

Tools

Four of them: search_documents, read_document, query_invoices for the ERP and create_ticket for the helpdesk. The schemas reject extra fields, and when a tool fails the error goes back to the model as an is_error result so it can try again.

Agent loop

A tool-use loop written by hand on the Anthropic Python SDK, stopped after 8 steps. Refusals, max_tokens and pause_turn each have their own handling. Earlier turns go back to the model as plain text, which is why a follow-up like "and in Berlin?" works. On Opus and Sonnet the API retries a refused request on another model.

Cost and speed

The demo runs on Haiku 5.5. In the evals it passed the same cases as Opus 5.5 for about 1/24 of the cost per answer, in roughly half the time. The system prompt and tool definitions are cached, and the trace prices every call by model.

Guards

Vercel's firewall allows each IP 8 questions an hour. The app adds a daily API budget and caps on question length, conversation length and steps. It only opens a ticket when someone asks for one.

Tests

The pytest suite covers retrieval, the tools, the agent loop (against a fake client), the API limits and the grader. Evals are a separate command because they call the real model and cost money.
